PREMIUM COLLECTION BY SANJIDA — READY TO RUN

1. Make sure Node.js LTS is installed.
2. Double-click START WEBSITE.bat.
3. The script installs Express if needed, starts the server, waits for it, then opens the storefront at http://localhost:10000/.

STORE: http://localhost:10000/
ADMIN: http://localhost:10000/admin

If the browser does not open automatically, copy http://localhost:10000/ into Chrome or Edge after the server window says the service is running.

TROUBLESHOOTING: If Chrome previously opened /admin, close that tab and use the URL opened by START WEBSITE.bat. The root URL / is the customer storefront; /admin is only for administration.
